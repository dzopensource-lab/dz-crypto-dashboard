# 📈 DZ Crypto Dashboard

**Real-time cryptocurrency market tracker built with vanilla JavaScript and Chart.js.**

[![Live Demo](https://img.shields.io/badge/Live_Demo-success?style=flat&logo=githubpages&logoColor=white)](https://dzopensource-lab.github.io/dz-crypto-dashboard)

---

## ✨ Features

- 🪙 Live prices for top 4 cryptocurrencies (Bitcoin, Ethereum, etc.)
- 📊 Interactive bar chart powered by Chart.js
- 🔄 Auto-refreshes every 60 seconds
- 🌙 Dark & elegant UI (no framework, pure CSS)
- ⚡ Zero dependencies (except Chart.js CDN)
- 📱 Fully responsive

---

## 🛠️ Tech Stack

`HTML5` · `CSS3` · `Vanilla JavaScript` · `Chart.js` · `CoinGecko API`
